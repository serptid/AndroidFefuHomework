# Используемый API
Описание:  
Публичный REST API, предоставляющий информацию о бесплатных free-to-play и MMO-играх: название, жанр, платформу, дату релиза, описание и другие метаданные.  
API не требует ключа доступа.

Base URL: `https://www.freetogame.com/api`

# Функциональность приложения

* Загрузка списка free-to-play игр
* Поиск по названию
* Просмотр детальной информации об игре
* Добавление и удаление игр из избранного
* Сохранение избранного в локальной базе данных Room
* Отображение сохранённого избранного после перезапуска приложения
* Обработка состояний загрузки и ошибок
* Внедрение зависимостей через Hilt


# Что было добавлено в четвёртом домашнем задании

В четвёртом домашнем задании приложение было расширено за счёт подключения локальной базы данных Room и внедрения зависимостей с помощью Hilt.

Room используется для хранения избранных игр на устройстве. Благодаря этому пользовательские данные сохраняются между запусками приложения.

Hilt используется для автоматического предоставления зависимостей, таких как Repository, API-сервис и база данных. Это позволило убрать ручное создание объектов в UI-слое и сделать архитектуру более чистой и расширяемой.

# Архитектурные изменения по сравнению с третьим домашним заданием

* Добавлен класс `GamesApplication` с аннотацией `@HiltAndroidApp`
* Добавлен Hilt-модуль для предоставления зависимостей
* Добавлена локальная база данных Room
* Добавлены `Entity`, `Dao` и `Database`
* Логика избранного перенесена в локальное хранилище
* `ViewModel` получает зависимости через конструктор
* Репозиторий работает как с API, так и с локальной БД
